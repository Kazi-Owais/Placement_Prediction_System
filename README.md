# 🎓 Placement Prediction Web App (ML + Streamlit)

An end-to-end Machine Learning web application that predicts whether a student is likely to be placed based on academic performance, skills, and extracurricular activities.

Built using **SVM (Support Vector Machine)** and deployed using **Streamlit** for real-time predictions.

---

## 🚀 Live Demo
👉 https://placement-predictionsystem.streamlit.app/

---

## 📌 Problem Statement

Students often struggle to understand their placement readiness.  
This project aims to predict placement chances using key academic and skill-based features.

---

## 🧠 Solution Overview

This project uses a supervised machine learning approach to classify students into:

- ✅ Placed  
- ❌ Not Placed  

The model learns from academic, technical, and skill-based features.

---

## ⚙️ Tech Stack

- Python 🐍  
- Pandas & NumPy  
- Scikit-learn (SVM Classifier)  
- Streamlit (Web App)  
- Joblib (Model Serialization)

## 📊 Features Used

### Input Features:
- CGPA  
- SSC Marks  
- HSC Marks  
- Internships  
- Projects  
- Workshops / Certifications  
- Aptitude Test Score  
- Soft Skills Rating  
- Extracurricular Activities  
- Placement Training  

### Engineered Features:
- Academic Score  
- Experience Score  
- Profile Score  
- Training Effectiveness
